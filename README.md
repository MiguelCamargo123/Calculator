# Calculator

## About

This project is a simple calculator built with JavaScript.
It performs basic arithmetic operations and was created to practice logic and JavaScript fundamentals.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Simple command-line interaction

## Usage

1. Clone or download the repository.
2. Open the project folder in your terminal.
3. Run the calculator with:

```bash
node calculator.js
```

4. Follow the on-screen instructions.
